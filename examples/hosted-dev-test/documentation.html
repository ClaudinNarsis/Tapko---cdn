Getting Started

Welcome to the Tapko Widget documentation! This guide will help you integrate our feedback widget into your application in just a few minutes.

Quick Start: Copy and paste the code below to get started immediately. You'll need your Project ID and API Key from the Tapko dashboard.

Installation

Choose your preferred installation method:

Using NPM

Install the Tapko widget via npm:

npm install @tapko/widget

Then import and initialize in your application:

import Tapko from '@tapko/widget'; await Tapko.init({ projectId: 'your-project-id', apiKey: 'your-api-key' });

Using CDN

Add the script tag to your HTML:

<script src="https://cdn.tapko.io/widget/latest/tapko-widget.js"></script> <script> await Tapko.init({ projectId: 'your-project-id', apiKey: 'your-api-key' }); </script>

Initialization

Initialize the Tapko widget with your project credentials. The widget will automatically render a floating button on your page.

await Tapko.init({ projectId: 'your-project-id', apiKey: 'your-api-key', userId: 'user-123', // Optional: Identify users });
Note: The init() method is asynchronous. Make sure to use await or handle the promise appropriately.

Configuration

Customize the widget behavior with these configuration options:

await Tapko.init({ projectId: 'your-project-id', apiKey: 'your-api-key', // User identification userId: 'user-123', userEmail: 'user@example.com', userName: 'John Doe', // Appearance theme: { primaryColor: '#6366f1', position: 'bottom-right', // 'bottom-right' | 'bottom-left' }, // Behavior autoCapture: true, // Capture screenshots automatically enableKeyboard: true, // Enable keyboard shortcuts });

Configuration Options

  • projectId (required): Your Tapko project ID
  • apiKey (required): Your Tapko API key
  • userId (optional): Unique identifier for the user
  • userEmail (optional): User's email address
  • userName (optional): User's display name
  • theme (optional): Customize widget appearance
  • autoCapture (optional): Enable automatic screenshot capture

API Methods

Control the widget programmatically using these methods:

Enter Feedback Mode

Programmatically trigger feedback mode:

Tapko.enterFeedbackMode();

Exit Feedback Mode

Exit feedback mode programmatically:

Tapko.exitFeedbackMode();

Get Status

Check the current state of the widget:

const status = Tapko.getProjectStatus(); console.log(status.isInFeedbackMode); // true or false

Other Methods

// Close all open feedback bubbles Tapko.closeAll(); // Get widget version const version = Tapko.getVersion(); // Show queue viewer (if enabled) Tapko.showQueueViewer();

Events

Listen to widget events to integrate with your application:

// Widget initialized window.addEventListener('tapko:initialized', (e) => { console.log('Widget ready', e.detail); }); // Feedback mode entered window.addEventListener('tapko:feedback:mode:entered', () => { console.log('User entered feedback mode'); }); // Feedback mode exited window.addEventListener('tapko:feedback:mode:exited', () => { console.log('User exited feedback mode'); }); // Comment submitted window.addEventListener('tapko:comment:submitted', (e) => { console.log('Feedback submitted', e.detail); }); // Comment queued (if queue system enabled) window.addEventListener('tapko:comment:queued', (e) => { console.log('Feedback queued', e.detail); }); // Error occurred window.addEventListener('tapko:error', (e) => { console.error('Widget error', e.detail); });

Customization

Customize the widget to match your brand:

await Tapko.init({ projectId: 'your-project-id', apiKey: 'your-api-key', theme: { // Colors primaryColor: '#6366f1', backgroundColor: '#ffffff', textColor: '#333333', // Position position: 'bottom-right', // or 'bottom-left' // Button buttonSize: 'medium', // 'small', 'medium', 'large' buttonText: 'Feedback', } });
Pro Tip: Use CSS custom properties for more advanced theming. See our advanced customization guide for details.

Troubleshooting

Widget not appearing

  • Check that your Project ID and API Key are correct
  • Ensure the script is loaded before calling init()
  • Check browser console for error messages
  • Verify your domain is whitelisted in Tapko dashboard

Feedback not submitting

  • Check your internet connection
  • Verify API key permissions in dashboard
  • Look for CORS errors in console
  • Ensure you haven't exceeded your plan limits
