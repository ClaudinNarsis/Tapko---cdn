Installation

Add Tapko to your website with just two lines of code:

<script src="dist/tapko-widget.js"></script> <script> Tapko.init({ projectId: 'your-project-id', apiKey: 'your-api-key', userId: 'user-123' // Optional: identify the current user }); </script>

Or use data attributes for auto-initialization:

<script src="dist/tapko-widget.js" data-tapko-project-id="your-project-id" data-tapko-api-key="your-api-key" data-tapko-user-id="user-123" ></script>
