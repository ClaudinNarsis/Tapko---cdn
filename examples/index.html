Tapko Widget

Gesture-free, fully discoverable feedback system

v2.0.0 — Technical Specification Demo

🎉 Key Features

  • Floating Entry Button: Always visible, click to enter feedback mode
  • No Hidden Gestures: Everything is explicit and discoverable
  • Single-Tap Comments: Just tap anywhere when in feedback mode
  • Explicit Drawing Mode: Optional drawing via "Draw on page" button
  • Visual Feedback Mode: 4% overlay tint shows you're in feedback mode

How to Use

  • Step 1: Click the floating button (bottom-right) to enter feedback mode
  • Step 2: Tap anywhere on the page to create a comment
  • Step 3 (Optional): Click "Draw on page" to add visual annotations
  • Step 4: Submit your feedback
  • Exit: Press ESC twice or click the floating button again to exit feedback mode
