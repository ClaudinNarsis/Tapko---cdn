Edge Case 1

Very Long Comment Text

Enter feedback mode and click this section. In the comment card, paste or type a 1000+ character comment. Verify it submits without truncation errors or payload issues.

This is a target paragraph for long-comment testing. The comment card should handle multi-paragraph text, line breaks, and extended descriptions gracefully. It should not truncate the text silently or throw an error when the comment exceeds a few hundred characters. Real-world feedback is often detailed — product managers leave thorough bug reports with steps to reproduce, expected versus actual behaviour, environment details, and screenshots references. The widget must handle all of this. Additionally, test pasting text copied from another document, which may include Unicode characters, smart quotes, em dashes, and other non-ASCII characters that sometimes trip up JSON serialization.

Edge Case 2

Special Characters in Comments

Submit comments containing each of the following in the text field:

Emoji: 🚀 🎉 💡 ⚠️ ❌ ✅ 🔥 🤔 😅 🎨
HTML entities: <script>alert('xss')</script> &amp; "quoted"
Quotes & apostrophes: "double" 'single' `backtick` «guillemet»
Special symbols: © ® ™ § ¶ † ‡ • … ← → ↑ ↓ ↔
Math: ∞ ≈ ≠ ≤ ≥ ± × ÷ √ ∑ ∏ ∫
Newlines & whitespace in comment box (press Enter between sentences)
Very long URL: https://example.com/path/to/page?param1=value1&param2=value2&param3=very-long-value-that-keeps-going-and-going

Edge Case 4

Comment on Dark Background

The comment card should remain readable against this dark section. The pin marker colour must be visible. The overlay tint should be perceptible even on dark backgrounds.

Click anywhere in this dark area while in feedback mode and verify: (1) pin is visible, (2) comment card text is legible, (3) overlay is distinguishable from the background.

Edge Case 6

Comment Card Viewport Clamping

Three coloured corner targets are pinned at the viewport edges (top-left, top-right, bottom-left). Enter feedback mode and click each corner target. The comment card must not appear off-screen — it should reposition itself to stay within the viewport.

Edge Case 7

Rapid Submit — Double-Submit Guard

Enter feedback mode, click to open a comment card, then click the Submit button multiple times quickly. Only one feedback item should be created — the widget should prevent duplicate submissions.

Edge Case 8

Offline Queue

Steps: (1) Open DevTools → Network → select "Offline". (2) Enter feedback mode and submit a comment. (3) Verify the QueueViewerModal shows the queued item. (4) Re-enable Network. (5) Verify queue retries and item is marked as synced.

  • Long text

  • Submit comment with newlines — line breaks preserved on pin hover
  • Special characters
  • Submit comment with emoji — renders correctly, no encoding error
  • Submit comment with HTML tags as literal text — not interpreted as HTML (XSS safe)
  • Submit comment with smart quotes and em dashes — no JSON parse error
  • RTL content
  • Comment card opens in correct position on RTL section
  • Pin marker visible on RTL content area
  • Dark background
  • Pin marker visible against dark background
  • Comment card text is readable (contrast OK)

  • Dynamic content

  • Pin coordinates correct on dynamically-added content
