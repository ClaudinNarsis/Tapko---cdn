How URL Secret Key Protection Works

1. No Security Object: Widget initializes successfully (security is optional)

2. Security Disabled: When is_url_secret_enabled: false, widget initializes without checking URL parameter

3. Security Enabled: When is_url_secret_enabled: true:

  • Widget looks for tapko_url_secret_key in URL parameters
  • If parameter is missing → Widget DOES NOT initialize
  • If parameter doesn't match url_secret_key from API → Widget DOES NOT initialize
  • If parameter matches → Widget initializes successfully

Test Cases

When is_url_secret_enabled: true and the URL parameter matches the expected value.
