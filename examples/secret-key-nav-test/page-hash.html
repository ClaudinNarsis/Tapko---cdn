Installation

Install Acme via npm or add the CDN script to your HTML.

npm install @acme/sdk

Then import and initialise:

import { Acme } from '@acme/sdk'
const client = new Acme({ apiKey: 'YOUR_KEY' })

Authentication

All API requests must include your API key in the Authorization header.

Authorization: Bearer YOUR_API_KEY

Keys can be created and revoked in Workspace → Settings → API keys.

Quick start

Create your first project in three lines:

const project = await client.projects.create({
  name: 'My first project'
})
console.log(project.id) // → prj_abc123

GET /projects

Returns a paginated list of all projects in the workspace.

GET https://api.acme.dev/v1/projects
?page=1&per_page=20&sort=updated_at

POST /tasks

Creates a new task inside a project. All fields except title are optional.

{
  "title": "Implement dark mode",
  "project_id": "prj_abc123",
  "assignee": "usr_xyz",
  "due_date": "2026-05-01",
  "priority": "high"
}

Rate limits

The API is rate limited to 300 requests per minute per API key. Responses include X-RateLimit-Remaining and X-RateLimit-Reset headers.

GitHub

Connect your GitHub repos to automatically link commits, PRs, and issues to Acme tasks. Requires repo OAuth scope.

Slack

Receive notifications in any Slack channel when tasks are created, completed, or commented on. Supports custom filters per channel.

Figma

Embed Figma frames directly in task descriptions and comments. Changes in Figma are reflected in Acme in real time.
